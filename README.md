## Indexierung

`index.html` setzt `noindex, nofollow`, zusätzlich schließt `robots.txt` alle Crawler inkl.
gängiger KI-Bots aus. Beides gilt nur für die GitHub-Pages-Domain, nicht für die Dateiansicht
im Repository selbst.
